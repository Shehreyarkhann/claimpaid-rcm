CO-146: Diagnosis is invalid for the dates of service reported

Group CO — Contractual Obligation · Denial Code Library · Updated October 29, 2026

What CO-146 means

The diagnosis is invalid for the dates of service reported. The ICD code on the claim is not a payable, valid code for when the service occurred — it may be deleted, not yet effective, or missing required characters.

What it usually means on a real remittance

CO-146 is a code-set maintenance denial. It spikes after the annual October 1 ICD-10 update, when last year's valid codes quietly retire, and it also catches truncated codes billed without the specificity the code set requires.

Common causes

  • The diagnosis code isn't valid for the date of service — codes are added, revised, and deleted every October 1
  • A code requiring more characters (4th–7th) was billed truncated
  • The diagnosis was valid when the encounter was documented but the claim was billed after a code-set change
  • A home-grown charge-master entry carries a retired code that was never updated

How to fix or appeal CO-146

  1. Identify why the code failed: deleted code, new code, or a truncated code missing required characters — code validity is checked against the date of service
  2. Find the correct current code for the documented diagnosis at the highest specificity the documentation supports
  3. Submit a corrected claim with the valid code
  4. Sweep the charge master and any favorites lists for the same retired code
  5. Add date-of-service code-validity checks to your scrubber, with special attention every October 1 code-set turnover
Corrected claim or appeal? Corrected claim with the valid code for that date of service. Pure data fix — no appeal needed.

The deadline angle

Every remedy above runs against a clock. Corrected claims and appeals have to land inside the payer's filing and appeal windows, and those windows are counted from the date of service — see the standard timely filing limits by payer and verify against your contract. CO-146 — frequently asked questions

Why would a diagnosis be 'invalid for the dates of service'?

ICD-10-CM updates take effect every October 1. A code valid for a September date of service may be invalid for an October one, and payers validate against the date of service, not the billing date.

What do I replace an invalid code with?

The corrected, currently valid code for the documented condition — never a different condition chosen because it's valid. If documentation supports a more specific code in the same family, that's the correction.

How do I prevent CO-146?

Annual code-set maintenance: update the charge master and EHR problem lists every October, and run a scrubber validity check keyed to the date of service. ClaimPaid's scrubber validates diagnosis codes against the service date before submission.
