CO-181: Procedure code is invalid on the date of service

Group CO — Contractual Obligation · Denial Code Library · Updated October 29, 2026

What CO-181 means

The procedure code is invalid on the date of service. The CPT or HCPCS code billed does not exist — or is not recognized — for when the service was performed.

What it usually means on a real remittance

CO-181 is the procedure-side twin of CO-146: a code-set currency problem. It spikes every January after the CPT/HCPCS turnover and whenever a charge master carries a retired code into the new year.

Common causes

  • The procedure code was deleted or replaced in the annual CPT/HCPCS update and the charge master wasn't refreshed
  • A payer-specific or temporary code was used outside its effective dates
  • The code is valid generally but not for this payer's program on that date (e.g. a code Medicare doesn't recognize)
  • A typo-level error: transposed digits created a code that doesn't exist for that date

How to fix or appeal CO-181

  1. Determine whether the code was retired, not yet effective, or simply wrong for this payer's program on the date of service
  2. Select the current valid code that describes the documented service (use the annual crosswalk for retired codes)
  3. Submit a corrected claim with the valid code
  4. Sweep the charge master, order sets, and favorites for the retired code — one bad entry generates denials all year
  5. Add procedure-code validity (by date of service) to your scrub rules
Corrected claim or appeal? Corrected claim with the valid code. Mechanical fix; appeals aren't the tool for a code that didn't exist.

The deadline angle

Every remedy above runs against a clock. Corrected claims and appeals have to land inside the payer's filing and appeal windows, and those windows are counted from the date of service — see the standard timely filing limits by payer and verify against your contract. CO-181 — frequently asked questions

Why does procedure-code validity depend on the date?

CPT and HCPCS update every January 1 (and HCPCS quarterly). Payers validate the code against the date of service — a code retired December 31 denies on a January claim even if it was fine all year.

What replaces a retired code?

The current replacement code that describes the same documented service. Annual code crosswalks (and your specialty society's guidance) map retired codes to their successors.

How do I prevent CO-181?

Date-of-service validity edits in the scrubber, plus a January charge-master review against the new code books. ClaimPaid's coding checks validate procedure codes against the service date before claims go out.
