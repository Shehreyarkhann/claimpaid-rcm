CO-97: Benefit included in another service already paid

Group CO — Contractual Obligation · Denial Code Library · Updated October 29, 2026

What CO-97 means

The benefit for this service is included in the payment or allowance for another service or procedure that has already been adjudicated. In plain terms: the payer considers this line already paid for, as part of a bigger service on the same claim or an earlier one.

What it usually means on a real remittance

You will usually see CO-97 on the secondary line of a pair: an E/M code next to a procedure, a component code next to a comprehensive code, or a service the National Correct Coding Initiative (NCCI) treats as integral to the primary procedure. The primary line pays; the bundled line zeroes out with no patient responsibility.

Common causes

  • The secondary service is genuinely part of the primary procedure under NCCI edits, and the claim was submitted without reviewing the edit pair
  • A distinct, separately identifiable service was performed but billed without modifier 59 (or an X-modifier: XS, XP, XU, XE)
  • Two providers in the same group billed overlapping components of the same encounter
  • The procedure was unbundled — component codes billed separately when a single comprehensive code describes the service

How to fix or appeal CO-97

  1. Pull the NCCI procedure-to-procedure edit pair for the two codes and check the modifier indicator: 0 means never separately payable, 1 means a modifier can separate them, 9 means the edit is inactive
  2. Read the documentation for the encounter: was the 'bundled' service a distinct session, separate site, or separate encounter? If the note doesn't say so, the denial is correct
  3. If the service was distinct, submit a corrected claim with the appropriate modifier (59 or the more specific X-modifier) and attach the documentation that establishes the distinction
  4. If the services were one combined service, accept the bundling, write off the denied line per the CO adjustment, and fix the coding pattern going forward
  5. Track repeat pairs by rendering provider — a recurring CO-97 on the same code pair is a charge-master or coding-habit problem, not a payer problem
Corrected claim or appeal? Corrected claim when documentation supports a separating modifier; accept the write-off when the bundling is correct. An appeal without a documentation-backed distinction almost never moves.

CO-97 — frequently asked questions

Can a CO-97 denial be appealed?

You can appeal when the bundled service was genuinely distinct and separately identifiable — a different session, a separate procedure on a different site or organ system, or a separate encounter — and the documentation proves it. Without that distinction in the record, the bundling stands.

Should I rebill with the comprehensive code instead?

When the services were truly performed as one combined service, yes — bill the single comprehensive code that describes the whole service. Unbundling a comprehensive code into its components is a compliance risk, not a billing strategy.

How do I catch CO-97 before submission?

A scrubber that checks NCCI procedure-to-procedure edits before submission flags the pair while the claim can still be fixed — either by adding the correct modifier with documentation support or by billing the comprehensive code.
